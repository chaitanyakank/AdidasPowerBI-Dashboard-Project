# AdidasPowerBI-Dashboard-Project
Interactive Adidas dashboard built with Power BI for analyzing sales and performance data.

Description:
This project is a Power BI dashboard built to analyze and visualize key performance indicators (KPIs) for Adidas. It provides valuable insights into sales trends, product categories, geographical performance, and customer behavior. The goal of this dashboard is to support data-driven decision-making by presenting clear and interactive visuals based on real or sample Adidas data.

📊 Key Features:
• Overview of total sales, profit, and quantity sold.
• Breakdown by product category and subcategory.
• Regional and country-wise sales performance.
• Trend analysis over time.
• Interactive filters and slicers for dynamic reporting.
